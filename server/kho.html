Xanh: đủ · Cam: thiếu · Đỏ: chưa có trong kho · Mờ: không lắp (DNP). Cùng một linh kiện dùng ở nhiều dòng thì tính chung. Bấm vào một dòng để chọn lại linh kiện hoặc đánh dấu DNP.

Nhập đơn hàng / kiểm kê từ file

Kéo thả file vào đây, hoặc
File đơn hàng xuất từ LCSC, Digi-Key, Mouser (CSV / XLSX), hoặc bảng tự làm (Taobao…) có cột Số lượng + MPN / mã. Linh kiện đã có thì cộng số lượng và thêm mã nhà cung cấp; chưa có thì tạo mới.

Mẹo

  • LCSC: My Orders → chi tiết đơn → Export (CSV/XLSX).
  • Digi-Key: Order History → đơn → Download CSV.
  • Mouser: Order History → đơn → Export to Excel (nếu là .xls cũ, mở Excel lưu lại .xlsx).
  • Taobao: tự làm bảng Excel cột MPN | Giá trị | Package | Số lượng | Link Taobao | Vị trí.
